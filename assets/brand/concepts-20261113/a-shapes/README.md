# A 方案：替代标志形态

用户已选定 A 的黑粉方向，并要求进一步比较斜切 TL 以外的标志形态。本目录延续 A 的颜色、字标和图标底板，仅新增符号候选，等待用户选定后再替换应用。

最终已选定 A2「光门」，与 A 黑粉主题一并正式替换。正式母版见 `assets/brand/`；本目录保留原候选，不作为构建入口。

- **A1 光标**：圆角提示符与竖向光标。优先表达终端，信息直接、缩小后仍清楚。
- **A2 光门**：开放的窗口轮廓与浮起的光点。表达连接与光，不依赖字母，可作为独立品牌符号。
- **A3 夜猫**：猫耳轮廓、提示符与下划线表情。偏开发者工具文化，个性更强。

各子目录提供 `mark.svg`、深浅背景 `logo.svg` / `logo-on-light.svg`、`app-icon.svg` 和对应 PNG。`comparison.png` 为三套同尺寸比较，包含 24 / 40 / 64 px 图标预览。

配色沿用 `../a-noir/theme-preview.css`：近黑 `#141217`、冷粉 `#F58CB8`、浅色字标 `#F8EDF4`。本轮未修改当前品牌文件、生产界面或本机 App；主题与标志最终确定后再执行构建、签名、安装和原生验证。

运行 `python3 assets/brand/concepts-20261113/a-shapes/generate.py` 可重新导出所有资源与展示板。字标直接复用 A 的已转路径母版，图标渲染使用项目自带 Tauri CLI。
