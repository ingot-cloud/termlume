# Termlume 品牌候选方案 · 2026-11-13

本目录仅保存供用户选择的方案和隔离预览。未替换当前品牌资源、生产界面或 `/Applications/Termlume.app`。用户选定后，再同步窗口标志、主题变量、图标资源及本机安装。

最终选择：用户已确认 A2「光门」与 A 的黑粉主题，并授权替换和更新本机 App。正式母版已提升至上一级品牌目录，窗口与主题同步采用该方案；本目录保留候选历史与隔离预览。

## A · Noir / 黑粉极简

斜切的 T 与 L 合为一个轮廓，字标采用较厚的几何无衬线字体。近黑的图标底和低饱和面板衬托冷粉色标志。界面把粉色用于活动标签、光标、主要动作和文件夹图标；绿色仍表示连接成功。三套中最适合保留专业工作台气质的一套。

## B · Wave / 柔光流线

一条连续曲线组成双弧，表示连接和流动；小写字标更轻盈。App 图标使用粉到紫的渐变、浅色曲线和微弱浮雕感。界面采用墨紫底、淡紫色强调，适合偏柔和、现代的风格。

## C · Pixel / 复古玫瑰

阶梯边框、像素提示符与等宽字标，保留终端工具的直接识别。App 图标采用柔粉底和暖黑色图形；界面使用暖黑、低饱和玫瑰色，适合偏复古、个人化的风格。

## 文件与预览

`comparison.png` 为三套并排比较。各子目录包含 `preview.png` 完整展示板、`logo.svg` / `logo-on-light.svg` 深浅背景字标、`mark.svg` 独立标志、`app-icon.svg` 图标母版、PNG 导出、`theme-preview.css` 配色提案及 `theme-preview.png` 界面截图。

所有字标转为路径，不依赖客户端字体。界面预览使用实际工作台渲染器与 `scripts/fixtures/workspace-preview.js` 的虚构数据；没有 SSH、SFTP、钥匙串、Git 或用户数据操作。预览中的命令输出为静态示例，没有实际执行。

可独立选择 Logo 图形和界面配色，例如 A 图标配 C 的低饱和玫瑰色。最终选定后需补齐浅色主题的语义颜色、键盘焦点与状态色检查，再完成原生安装验收。

再生成：运行 `python3 assets/brand/concepts-20261113/generate.py` 导出矢量和 PNG；`node assets/brand/concepts-20261113/render-ui.cjs` 使用隔离的无头 Chrome 捕获实际界面；最后运行 `python3 assets/brand/concepts-20261113/compose-previews.py` 合成展示板。生成所用 macOS 字体为 Avenir Next 与 Courier New Bold，所需 Python 包为 fontTools 和 Pillow。

本轮预览验证：所有 SVG 可解析、PNG 可解码，App 图标外围透明；已人工查看三套完整展示板及实际界面截图。三套主题正文、辅助文字和强调色在四种主要表面上的最低对比度分别约 5.94:1、6.00:1、6.18:1，主要按钮文字对比度分别约 8.83:1、8.57:1、7.59:1。没有执行应用构建、安装或重启，等待用户选定。
